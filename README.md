# formz-snippets — VS Code Extension Files

This document contains the complete extension skeleton and files for the `formz-snippets` VS Code extension (publisher: `paanoop`).

## Folder structure

```
formz-snippets/
├── package.json
├── README.md
└── snippets/
    └── formz.code-snippets
```

### Main snippet prefixes
- `formzInputString`
- `formzInputNullable`
- `formzInputInt`
- `formzInputDouble`
- `formzInputEmail`
- `formzInputPassword`
- `formzInputMobile`
- `formzInputEnum`
- `formzInputDate`
- `formzInputOptional`
- `formzInputRegex`
- `formzInputPhoneCC`
- `formzInputUsername`
- `formzInputOtp`
- `formzInputUrl`
- `formzInputJson`

**Tip:** When the snippet expands, use `Esc` to jump between placeholders and avoid pressing `Enter` inside a placeholder (pressing Enter may accept an auto-complete suggestion). That ensures placeholders are replaced correctly across the file.
